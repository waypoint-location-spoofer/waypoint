# Install WayPoint

Choose your computer:

- **[Windows setup](docs/WINDOWS.md)**
- **[Mac setup](docs/MAC.md)**

Both guides use the ready-made IPA. An IPA is an iPhone app file. You install it with your own Apple account using Sideloadly, a separate installation tool. Xcode is optional for people who want to build the source themselves.

After installation, complete [iPhone setup](docs/IPHONE-SETUP.md). You need your own pairing file. Never use someone else's file or share yours.

This is an experimental release. A successful build does not mean it works on every iPhone or iOS version.
