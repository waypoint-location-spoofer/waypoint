# Start here

The setup guides now cover both computers:

1. Install the app using the [Windows guide](docs/WINDOWS.md) or [Mac guide](docs/MAC.md).
2. Finish [iPhone setup](docs/IPHONE-SETUP.md).
3. Read [weekly renewal](docs/RENEW.md) so the app does not expire unexpectedly.

For mobile data, try the [cellular guide](CELLULAR-TEST.md) after setup works on Wi-Fi.

The app has been compiled successfully, but its behavior on real phones is not yet verified. Some screens in version 0.2 still refer only to a Mac. You can use Windows for the IPA installation and pairing steps described here.

Developers can use the separate [Xcode build guide](docs/BUILD.md).
